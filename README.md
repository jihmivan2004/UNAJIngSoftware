# UNAJIngSoftware

## Proyecto académico de Ingeniería de Software

Desarrollo de una arquitectura basada en microservicios utilizando Java y Spring Boot.

### Tecnologías utilizadas

- Java JDK 17
- Spring Boot
- Spring Cloud Config Server
- Apache Maven
- PostgreSQL
- pgAdmin 4
- Swagger / OpenAPI
- Git y GitHub
- IntelliJ IDEA

### Microservicios

**1. ms-config-server**
- Servidor centralizado de configuración.
- Obtiene archivos YAML desde GitHub.
- Puerto: 7070.

**2. ms-catalogo-service**
- Administración de categorías.
- Operaciones CRUD.
- Conexión con PostgreSQL.
- Documentación mediante Swagger.
- Puerto: 8081.

### Base de datos

Nombre: `ms_catalogo`

Motor: PostgreSQL.
